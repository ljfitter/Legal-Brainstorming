# Legal-Brainstorming
Repository for legal research frameworks, brainstorming and legal product design.

## Contents

- [`frameworks/legal-research-delivery-framework.md`](frameworks/legal-research-delivery-framework.md) — operating model for running legal research alongside a 2-week Scrum cadence, with a traceability matrix mapping legal requirements to product design specs.
- [`.github/ISSUE_TEMPLATE/legal-requirement-card.yml`](.github/ISSUE_TEMPLATE/legal-requirement-card.yml) — GitHub issue template for filing a single Legal Requirement Card.
- [`templates/traceability-matrix.csv`](templates/traceability-matrix.csv) / [`.md`](templates/traceability-matrix.md) — starter Requirements Traceability Matrix (import the CSV into Airtable/Sheets/Excel, or use the Jira/Linear custom-field equivalent described in the framework doc).
